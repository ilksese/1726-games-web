# 代码规范

给改这个仓库的人看。先沿用所在文件的写法，再套下面的规则。

## 语言

- 玩家能看见的文案用中文，句子写完。
- 代码、标识符、提交说明用英文。
- 注释只写代码看不出来的约束。类型字段用 JSDoc，一句话说明用途和边界。

## 前端

- 新游戏放在 `packages/<name>/src/`。URL 不出现 `packages/`。
- 已有 React 的包继续用函数组件，不新引框架。原有 vanilla DOM 的包不要改成 React。
- 规则、发牌、校验放在不引用 DOM 的模块里。组件只负责展示和操作。
- 页面不执行口头规则。技能效果写在文案里，由玩家在桌上执行。
- 身份走查询参数 `name` 和 `key`。中文名不放 HTTP 头。
- 样式跟所在包走。万象麻将用 `style.css` 和 `wx-` 前缀，不混进别的游戏。
- 不写死端口。前端读 `VITE_1726_GAME_PORT`，房间服务读 `VITE_1726_SERVER_PORT`。

## Go 房间服务

- 房间状态只在锁内改。对外快照不带私人手牌。
- 错误用 `actionError(code, message)`。`message` 是玩家能看懂的中文，不暴露内部原因。
- 牌的编号在前端和 Go 里必须一致。改编号要两边一起改，并改对应测试里的牌山数量。
- `go test ./internal/room/` 能覆盖的规则，改完要跑。

## 不要做

- 不把密钥、房间 key、私人手牌写进日志或提交。
- 不在页面上判定麻将牌是否合法。
- 不给还没定的交互加确认框、倒计时或自动通过。
